# Segurança

Use a versão marcada como **Latest**. A versão anterior é mantida somente para
recuperação orientada; versões históricas retiradas não recebem suporte.

Para suspeitas de vulnerabilidade, use o
[relato privado de segurança](https://github.com/jstoreuser/updater-releases/security/advisories/new).
Descreva a versão, o comportamento e os passos mínimos para reproduzir, usando
dados sintéticos. Não publique a suspeita com segredos em uma issue pública.

Para dúvidas comuns, use as
[issues de suporte](https://github.com/jstoreuser/updater-releases/issues).
Revise qualquer diagnóstico antes de compartilhá-lo. Não envie credenciais,
tokens, arquivos pessoais, saves ou Mods.

Assinaturas de atualização e SHA-256 ajudam a verificar a origem e os bytes.
Não representam certificado Authenticode ou garantia de aceitação pelo Windows.
Não desative Defender, SmartScreen ou Smart App Control para executar o cliente.
